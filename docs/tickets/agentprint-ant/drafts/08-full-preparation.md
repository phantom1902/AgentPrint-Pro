## What to build

T08：生成全量缓存与有效数据覆盖报告。

CPU真实样本验收通过后，研究者获得全部现有原始捕获和完整标注按既定规则处理的两任务官方train/val/test缓存、有效/排除清单及覆盖报告，知道实际可用数据规模与正式训练资格。

## Acceptance criteria

- [ ] 只在T07成功后启动全量prepare，覆盖全部当前原始PCAP和现有完整标注；保留官方划分和固定标签，不删除原始数据，不猜偏移或补端点，不复制片段PCAP。
- [ ] 在已约定数据/运行根中生成分片uint64缓存、清单、标签映射及兼容标识，采用单进程与既定完成分片恢复机制；记录实际文件/样本数、耗时、存储和执行代码SHA。
- [ ] 分任务/split/类别报告有效和排除数量、原因、支持数和覆盖率；缺日志不误排场景，方向缺失等共同排除不漏报，不把26份抽样覆盖率冒充全量统计。
- [ ] 校验有效清单与缓存行对应、重复/遗漏、时间/标签/端点来源和可读取性；报告test数据质量，但不执行用于选择模型/参数的test成绩分析。
- [ ] 全量训练缺预定类别时明确报告受影响任务被正式训练门控阻止，不擅自删除类别或停止另一任务的数据交付；该质量结论可以作为如实交付结果，不伪称完整类别可训练。
- [ ] 保留当前兼容完成产物和历史运行，异常按既定语义处理；程序错误导致未完成时不得标记全量完成，提供恢复依据。
- [ ] 完成后提供两任务全量产物标识和可复核质量汇总；本票不启动正式GPU训练或自动开卡。
