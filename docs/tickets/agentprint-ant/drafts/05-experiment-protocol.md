## What to build

T05：完成raw/log1p比较与正式实验协议。

研究者可以对两个独立任务运行四种预声明配置，用相同样本比较raw/log1p，以验证指标选择模型和主配置，并按既定口径报告测试结果。使用小构造数据验证协议，不在本票启动四次正式GPU实验。

## Acceptance criteria

- [ ] 从同一uint64缓存读取float32 raw或逐元素log1p，四份实验配置共享公共YAML且只包含相应差异；固定统计/方向/类别映射，不生成第二套变换缓存。
- [ ] 两任务独立使用普通无权重CE，模型内部无softmax，其他比较条件一致。正式参数为Adam、初始LR5e-4、weight_decay1e-3、batch200、总30epochs，第e轮LR为5e-4乘0.2的e/30次方，e为0至29，seed42。
- [ ] 主Macro-F1只平均固定有效split清单中有真实样本的类别，集合不随预测变化；同步报告Accuracy、逐类支持数/覆盖率，Primitive另报固定47类缺类计零的辅助Macro-F1，头始终为47。
- [ ] 每轮验证选best，同分保留较早epoch；每任务按验证主Macro-F1选变换，同分raw优先。四配置各自验证最优checkpoint均可在test评估，标记验证选出的主配置，不用test结果作选择。
- [ ] 全量有效训练集缺预定5类或47类时，报告缺类并阻止受影响任务的正式训练，不删类或放宽质量规则；明确允许有意缩小的独立CPU验收配置缺类，不改变val/test缺类口径。
- [ ] FP32、固定seed、禁用AMP/TF32/cuDNN benchmark、可用的确定性要求、DataLoader workers0和正式配置串行执行落实到可核对配置；OOM/非有限损失/不支持模式停止报告，不静默降配。
- [ ] 通过公开命令及可手算真实/预测标签验证四配置可用、raw/log1p同源、指标/缺类/同分与验证测试隔离；小样本运行不更改正式配置，也不被报告为正式30轮实验。
