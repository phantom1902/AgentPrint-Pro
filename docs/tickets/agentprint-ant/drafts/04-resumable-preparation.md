## What to build

T04：中断后恢复兼容的分片预处理。

研究者在prepare中断后再次执行相同任务，可以复用已完成且兼容的分片，只重建未完成部分；数据或配置变化时获得明确的不兼容说明。恢复产物能够继续训练评估，不需要第二套逐Episode缓存或切分PCAP。

## Acceptance criteria

- [ ] 按任务/split组织uint64原始统计，每片1024个完整样本、末片可不足，使用内存映射读取；只从原始PCAP生成，不保存片段PCAP或Episode级临时MTAM。
- [ ] 完整分片为提交单位，中断后已完成且兼容分片保留，未提交分片重建；恢复后有效/排除清单与缓存索引不遗漏、不重复，不把半片当作完成。
- [ ] 兼容性涵盖预处理版本、配置、文件清单、PCAP相对位置/大小/mtime，以及小标注/端点元数据内容哈希；不额外全量哈希PCAP，不声称可识别大小与mtime均未变的内容替换。
- [ ] 不兼容时给出原因，不静默混用旧缓存；预料质量排除与程序异常的既定行为保持一致。
- [ ] 场景构造数据跨越1024分片边界；在可控中断后通过公开命令恢复，最终样本/统计与未中断运行一致，恢复产物可训练评估。使用小型原始捕获生成多个有效样本，不靠重复扫描105GB数据完成测试。
- [ ] 缓存机制遵守T01已建立的通用task/split和清单契约，不重定义标签或标注区间；Primitive真实接入在后续集成验收核对，因此本票不人为依赖T02。
