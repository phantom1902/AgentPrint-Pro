## What to build

T02：跑通标注片段的47类独立分类。

研究者能将一个Episode的完整捕获和已有消息标注转换为给定片段，使用公开命令训练、评估47类Primitive分类器。它与场景任务共用适用的解析/MTAM/模型定义，分别产生样本、损失、权重和结果。

## Acceptance criteria

- [ ] 仅使用当前N001–N047本体并固定编号0–46；场景保持原五类映射，任何split缺类不改变头大小或标签编号。
- [ ] 片段从当前标注起点到下一起点，末段到捕获结束；时间为整数纳秒，保留原标注行号和来源，所有片段共用Episode端点依据。
- [ ] 重复起点组全部排除对应区间，末组到捕获结束；保留其他有效片段，不跨排除区间拼接，也不把终点包移给前一有效片段。
- [ ] 无可用包、零时长或无法可靠对齐的片段按原因排除，不增加最少包/最短时长门槛，不猜测时钟偏移。片段异常或缺日志不自动取消场景资格。
- [ ] 每个给定片段按完整标注区间等分1800槽，边界归属遵守规格，不按过滤后的首末包缩短区间；生成有效/排除清单和可读取的缓存行。
- [ ] prepare→train→evaluate在构造标注捕获上实际跑通47类raw分类，独立于场景权重/结果；使用普通CE，输出真实指标和支持数。
- [ ] 公共命令级测试覆盖相邻起点、重复起点、无效末段、捕获终点及场景资格独立性；重新运行T01场景闭环，证明新任务未改变其行为。
