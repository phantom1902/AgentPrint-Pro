## What to build

T01：跑通场景分类的最小完整闭环。

研究者能从一组可手工核对的有效Episode捕获出发，通过公开prepare、train、evaluate命令生成场景MTAM、训练RF分类器并查看验证结果。这是后续扩展的可运行起点，范围先覆盖已确定的Ethernet/IPv4/TCP清晰运行端成功路径，不冒充完整ANT数据支持。现有四项ADR、两任务边界和规格中的正式约束继续适用，不改造旧风险套件。

## Acceptance criteria

- [ ] 独立agentprint入口可读取公共YAML和场景实验配置，校验未知/非法配置并支持已确认的运行项覆盖；不增加未批准的命令行实验参数入口。
- [ ] 由构造PCAP的唯一私网TCP初始SYN发起端、包参与数唯一第一规则确定运行端；已支持路径按源/目的地址计算上下行，非支持输入明确拒绝或报告，不静默猜测方向。
- [ ] 以完整捕获区间构造包数/IP字节量×上行/下行×1800槽MTAM，使用IP总长度、保留控制包和重传；内部边界归新槽，捕获终点入末槽。手算预期值与产物一致。
- [ ] 输出uint64分片NPY、有效/排除JSONL、固定五类标签映射和可追溯缓存索引；来源、时间、质量及版本契约按规格建立，片段专属字段为空。首次就采用最终1024完整样本分片接口，不引入之后必须废弃的临时样本格式。
- [ ] 使用真实RF参考结构及已批准的双统计适配完成场景raw训练和验证，普通无权重CE、不先softmax；以验证主Macro-F1保存best，报告Accuracy和类别支持数。最小路径不使用替代模型或假训练结果。
- [ ] 公开模型接受批输入[B,2,2,1800]并支持K=5/47两种输出，保留参考reshape、末层BN/ReLU及初始化；两种输出均能得到有限损失并反向传播。此项不表示片段任务命令已完成。
- [ ] 临时目录中的命令级测试跑通PCAP→缓存/清单→训练→验证评估；期望统计独立手算，测试不依赖私有helper调用。提交可复现演示及当前支持边界，后续ticket在此闭环上扩展。
