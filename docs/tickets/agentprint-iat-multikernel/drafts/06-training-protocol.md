# T06：执行可恢复的v2训练与严格停止协议

## What to build

从公共train/evaluate入口执行新锚点、验证选模和可恢复训练，支持正式训练的严格停止接口，并将2轮smoke预算结束与收敛状态明确区分。

## Acceptance criteria

- [ ] v2使用Adam、width2、学习率0.001、weight_decay0.001、batch200、dropout_2d0.05、dropout_1d0.1；学习率为0.001乘0.5的epoch/30次方，下限0.000001，epoch从0计，不复用旧硬编码公式。
- [ ] 普通不加权CE，实际最佳验证Macro-F1选模、同分较早epoch；0.001显著提升阈值只用于停止，不阻止checkpoint更新。
- [ ] 正式接口至少60、最多200轮；连续20轮无至少0.001的显著F1提升且相邻两段10轮平均验证损失相对改善不足1%才收敛，上限停止不误报收敛。损失前段均值为0的既有处理保留。
- [ ] 真实运行仍不启动正式训练。通过已有停止规则测试先例的合成历史及公共smoke配置验证边界/入口接线，不为测停止规则消耗真实全量轮次。
- [ ] 固定seed、FP32、workers0、数值线程4，关闭AMP、TF32及cudnn benchmark；非有限损失/OOM/资源不足停止报告，不自动缩减模型或样本。
- [ ] 按完整epoch恢复模型、Adam、RNG、shuffle、best和停止历史，超前日志按既有合同处理；合成数据中恢复结果与一次完成一致。
- [ ] 模型/特征/拟合/缓存/变换/训练身份不同的候选和恢复请求被隔离或拒绝；在本票可用单核/IAT关闭合成闭环验证通用协议，不要求后续变体已完成。
- [ ] v1原训练、评估和恢复协议保持不变，不重新训练真实MTAM实验，不读取真实test。
