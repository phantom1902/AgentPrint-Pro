# T01：跑通兼容旧协议的v2最小闭环

## What to build

使用v2配置在IAT关闭、单核CNN条件下，经现有公共prepare、train、evaluate入口完成合成Episode的场景分类闭环；新实验携带可重建的模型与特征身份，原v1流程保持原样。这是后续功能的有限前置改造，不是全套横向重构。

## Acceptance criteria

- [ ] v2明确表达IAT开关、模型变体、输入变换、拟合/补充缓存引用及训练配置；本票演示仅启用已实现的单核、IAT关闭组合，未实现组合明确报错而非回退。
- [ ] 以合成数据验证公共prepare→train→evaluate，raw/log1p可用，width=2及已批准锚点可从配置进入模型与优化器；训练仅为合成接口测试，不运行真实MTAM重复实验。
- [ ] 模型构造支持2/10输入通道的公开接口，输出五类logits，有限CE与梯度；本票不生成IAT缓存。
- [ ] 特征/模型扩展版本和定义进入新checkpoint，评估从保存定义重建；选模身份预留拟合、缓存、变体等合同，不仅按输入变换分组。
- [ ] v1仍按原规则严格解析，不注入新字段，不改变旧配置/预处理指纹；原参数下模块关闭时初始化和输出一致。
- [ ] 已有场景、Primitive及旧恢复回归保持通过；新功能不要求改写旧缓存或旧checkpoint。
- [ ] 公共入口配置校验、加载/模型/训练身份接口的明确合同已随可运行闭环提交，供后续分支复用；不为尚未完成的功能返回伪成功。

## Blocked by

None (can start immediately).
