# T07：集成十二配置并核验旧产物与恢复

## What to build

把IAT补充缓存、两种多核和v2训练协议汇合成同一可用版本，以已确认的公共测试边界证明所有配置能正确训练/评估、恢复和拒绝不兼容产物，且旧研究产物仍可使用。

## Acceptance criteria

- [x] 同一集成版本支持IAT开/关×单核/替换/前置×raw/log1p共12配置；全部通过必要的公开模型接口检查，不把此项当作12组真实实验。
- [x] IAT开启的6配置从合成PCAP经公共fit-bins→prepare→train→evaluate运行，使用同一拟合产物，验证真实缓存形状、log1p全通道和模型重建。
- [x] 对拟合Episode、预处理分片、训练epoch中断验证组合恢复；计数/身份与完整状态一致；覆盖不同变体候选隔离、smoke/全量身份和来源变更拒绝。
- [x] 使用真正旧v1配置、缓存及checkpoint核验读取、评估和恢复，并保留原参数初始化/输出一致性；不能只由新实现重建所谓旧夹具。
- [x] test评估路径只用合成夹具验证，选模不依赖test存在，集成测试不读取真实test。
- [x] CPU自动化测试给出通过、失败、未执行清单；已有场景/Primitive相关回归通过。修正集成冲突不能改变已确认合同或偷偷加预算。
- [x] 产物、命令及失败证据可复查，集成提交明确；下一票只能基于此已验收版本运行真实小样本。

## Blocked by

- T04：运行无残差的前置多核模型。
- T05：跑通可恢复的十通道IAT分类闭环。
- T06：执行可恢复的v2训练与严格停止协议。
