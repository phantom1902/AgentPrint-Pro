# T02：通过公共命令拟合并恢复共享IAT桶

## What to build

执行显式fit-bins，从训练Episode生成可复用、可审计、可恢复的八桶定义，供后续prepare消费；研究者可以独立检查train-only拟合、时间语义与抽样身份。

## Acceptance criteria

- [ ] 复用原有效包、运行端方向及完整捕获区间；逐Episode紧凑数值记录稳定按整数纳秒排序，同时间戳保留原记录顺序并报告逆序情况。
- [ ] IAT来自跨方向/连接的相邻有效包；首包无IAT，真实零间隔与大于零间隔区分；暴露给后续统计的当前包时间/方向语义一致。
- [ ] 仅train拟合，每Episode最多4096个大于零间隔均匀无放回抽样；seed42与稳定sample_id共同派生种子，遍历顺序及训练种子不改变拟合。
- [ ] Episode等权混合经验分布，六个分界取1/7至6/7达到累计权重的实际整数值、不插值；保留重复边界，零桶独立、边界归右、末桶无上限。
- [ ] 无大于零间隔的Episode只退出拟合并报告，整个拟合池均无此类间隔时失败；不改变分类资格，不伪造边界。
- [ ] 产物记录train清单、来源身份、规则、种子、边界、参与/未参与统计和指纹，smoke与全量身份明确区分；跨模型/变换/训练种子可共用。
- [ ] 按Episode提交最多4096抽样值及身份，中断恢复与一次完成的拟合一致，来源/规则变化拒绝复用；不保存完整逐包序列或原始包内容。
- [ ] 以手算合成PCAP从公共fit-bins验证语义、权重、边界与恢复，不读取真实test；资源不足明确失败，不跳过样本或偷偷改用其他排序方案。
