# T05：跑通可恢复的十通道IAT分类闭环

## What to build

使用已拟合桶，通过公共prepare为选定Episode生成IAT补充缓存，再与已有MTAM关联，使用单核CNN完成十通道训练和验证评估；中断预处理后可继续。

## Acceptance criteria

- [ ] prepare读取显式fit-bins产物，不隐式拟合；按当前包方向/原1800槽统计全部有效间隔，不将拟合抽样当作统计抽样，不改变捕获范围或基础MTAM。
- [ ] IAT为uint64、8桶×2方向×1800槽，256样本一片、末片可不足；手算验证首包无间隔、零桶、边界归右、重复边界及末槽/末桶。
- [ ] 与原1024样本分片按sample_id关联，支持不同分片边界；缺失基础缓存、身份不符或sample_id缺失明确停止，不自动补建。
- [ ] 补充缓存绑定来源、基础缓存、清单与拟合指纹；错误拟合或来源变化拒绝复用，smoke产物不能冒充全量。
- [ ] 合并为批次×10通道×2方向×1800槽，raw保留计数，log1p作用于全部10通道，无额外归一化。
- [ ] 公共fit-bins→prepare→train→evaluate在合成PCAP上完成IAT开启、单核、raw/log1p闭环；checkpoint重建核验拟合及双缓存身份。
- [ ] 按完整IAT分片提交恢复，中断后最终计数/清单/身份与一次完成一致，未完成分片不能冒充已提交。
- [ ] 沿用样本资格，无大于零间隔Episode仍可分类；资源不足/非有限损失/OOM明确失败，不读取真实test，不保存逐包产物。
