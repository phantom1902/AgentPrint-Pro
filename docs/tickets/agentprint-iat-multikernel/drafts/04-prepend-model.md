# T04：运行无残差的前置多核模型

## What to build

通过v2配置独立选择前置型多核，在完整原CNN前增加时间尺度融合，完成合成数据训练与保存模型的重载评估。

## Acceptance criteria

- [ ] 复用已验证的3/5/7分支、22/21/21通道、same补零、Conv/BN/ReLU及初始化规则，不另造不同的多核实现。
- [ ] 拼接64通道后投影回输入2或10通道，再进入完整CNN；width=2时原首层输出64，采用直接CNN(F(x))，不加残差。
- [ ] 前置型与替换型为独立变体，配置不默认串联两者，身份及checkpoint可区分；错误组合不得静默解释为另一变体。
- [ ] 公开接口覆盖2/10通道、raw/log1p的五类输出、有限CE及反向传播，报告实际参数量。
- [ ] 合成MTAM经公共train/evaluate跑通前置型训练、选模及保存定义重建；真实IAT闭环在后续汇合票验证，不以接口张量测试替代。
- [ ] 原单核和替换型回归保持通过，不启动真实IAT关闭训练实验。
