# T03：运行替换首单元的多核模型

## What to build

通过v2配置选择替换型多核，完成合成MTAM上的公共训练和checkpoint重载评估；多核在原时间槽轴融合3/5/7槽观察范围，并提供前置型可复用的同一多核单元。

## Acceptance criteria

- [ ] 方向核高3、时间核长3/5/7，stride1，方向补零1、时间补零1/2/3，分支输出长度保持1800；输出通道22/21/21。
- [ ] 每分支Conv→BN→ReLU，拼接64通道后1×1→BN→ReLU投影到64，整体替换原第一个Conv/BN/ReLU；不重复旧首个BN/ReLU、不裁剪回旧首层长度。
- [ ] width=2，沿用后续二维前端、原reshape及一维分类器；在reshape前应用多核，实际形状兼容后续池化并输出五类logits。
- [ ] 新增Conv2d沿用RF初始化，Conv1d保持原行为，模型从头初始化；报告实际参数量，不宣称严格等参数。
- [ ] IAT关闭的raw/log1p在合成数据上经公共train/evaluate可运行，保存变体身份并从checkpoint正确重建。
- [ ] 公开模型接口以2/10通道输入验证形状、有限CE及梯度；10通道只用合成张量，不依赖尚未完成的真实IAT路径。
- [ ] 原单核/v1模型回归通过；提供前置型可直接复用的多核构造合同，避免两票各写不同核、初始化或通道规则。
