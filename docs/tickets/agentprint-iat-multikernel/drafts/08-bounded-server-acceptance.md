# T08：完成六配置真实小样本验收并交付证据

## What to build

在服务器数据盘对已集成版本执行确定性的有限真实Episode验收，从选样、train拟合到补充缓存、六组训练、验证评估与恢复，交付真实运行证据。

## Acceptance criteria

- [x] 实现小样本验收入口并用合成清单检验预算/选样/test隔离，再基于已提交实现选择真实样本；所有报告记录准确Git版本。
- [x] 现有有效清单中每类train最多4、val最多2，总计最多20/10；PCAP小者优先，sample_id打破并列，不要求消息标注存在，不另改样本资格。
- [x] 仅所选train拟合、所选train/val准备，复用已有正确基础MTAM；缺失或身份不符立即报告，产物标记smoke，不代替全量拟合。
- [x] 只对IAT开启的单核/替换/前置×raw/log1p六组串行执行，各seed42、2轮、batch200及共同锚点；不跑真实IAT关闭组，不追加调参或正式训练。
- [x] CPU执行单元/集成检查；六组真实训练优先可用GPU、无GPU则CPU，保持FP32、workers0、数值线程4，不自动缩减模型或样本。
- [x] 验证最佳checkpoint重载、验证集指标和恢复路径；不读取真实test，不用smoke分数排名方法或宣称收敛。
- [x] 全部服务器新增拟合/缓存/暂存/日志/checkpoint/报告位于已指定数据盘内，原始数据不改写；不得因磁盘不足隐式改存系统盘。
- [x] 报告记录选择清单、fit/cache身份、实际参数量、设备、每组命令/轮数/指标、恢复证据和失败项；通过/失败/未执行如实区分。
- [x] 提交可复查的轻量交付证据与复现说明，实际大数据和checkpoint保留在指定数据盘；全量预处理和正式训练明确等待后续指令。
