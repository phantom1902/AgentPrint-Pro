## 2. IAT定义与时间槽

处理单位为一个完整episode。沿用现有MTAM的有效包、捕获区间和运行端方向判定；按整数纳秒时间稳定排序，同时间戳维持原PCAP记录顺序。报告原记录的时间逆序情况。

排序后有效包为p0…p(n-1)，对i≥1计算delta_i=t_i−t_(i-1)。前驱跨方向、跨连接；统计方向取当前包p_i的方向。delta_i大于零表示时间间隔大于零，与入站/出站无关。首个有效包没有IAT，仍计入原MTAM包数与字节量。

每个间隔计入当前包所在的原1800槽之一：完整捕获范围为[start_ns,end_ns]，槽号沿用min((t_i−start_ns)×1800//(end_ns−start_ns),1799)，不以过滤后首末包重新确定范围。样本资格与退化区间处理沿用原流程。

逐episode只保留紧凑数值记录供内存稳定排序，不保存原始包内容或完整逐包序列产物。资源不足或OOM停止报告，不暗中跳过样本，不实现外部排序。

## 3. 桶边界拟合

固定8桶：桶0仅容纳真实零间隔；桶1–7容纳大于零的间隔。两个方向共享边界，但分方向累计。边界仅使用train拟合，固定应用于val及以后明确授权的test评估。

每个训练episode最多均匀无放回抽取4096个大于零间隔，不足时全取。固定抽样seed=42，结合稳定sample_id派生episode种子，使遍历顺序和训练种子不改变拟合产物。抽样仅近似拟合分布，实际特征统计使用全部有效间隔。

设参与拟合的episode数为E，第e个抽样数为m_e，每个抽样值权重为1/(E×m_e)。这样每个episode总权重相同，而非全局每个包等权，也非直接平均各episode分位点。

从此加权经验分布取1/7、2/7、…、6/7六个分位点：取累计权重达到目标比例的实际整数纳秒值，不插值。对大于零的delta，桶号等于1加上“小于或等于delta的边界个数”，因此恰落边界时归右桶。零间隔始终归桶0。

重复边界保留，仍输出8桶；允许并报告空桶，不加抖动。末桶覆盖所有更大间隔。无大于零间隔的episode只从拟合分布剔除并报告，分类资格不变；整个拟合池均无大于零间隔时失败，不伪造边界。

拟合产物记录所用train清单、来源身份、抽样规则及种子、分位点、参与/未参与episode统计与指纹。所有模型、raw/log1p、训练种子共用同一拟合产物。小样本拟合显式标记smoke，不能冒充或替代全量拟合。

## 4. 输入表示与缓存

原MTAM保持uint64、[2,2,1800]，统计维为包数与IP字节量。IAT独立补充缓存为uint64、[8,2,1800]，每个元素为该桶、方向、时间槽中的间隔数量。合并输入为[B,10,2,1800]；关闭IAT时为[B,2,2,1800]。

raw使用原计数；log1p逐元素作用于全部输入统计，包含IAT计数。不额外归一化或标准化。

IAT每样本230400字节，即225 KiB，为原MTAM数组空间的4倍。每256样本一片，整片数组56.25 MiB，末片可不足；此估算不含清单及元数据。原缓存1024样本分片不改动，两者按sample_id关联，不要求分片边界一致。

补充缓存必须绑定sample_id、来源身份、基础缓存身份及拟合指纹。基础MTAM缺失、不兼容或缺少所选sample_id时停止并明确报告，不自动补建。原缓存不含逐包时间，不能从其反推IAT，仍须读取所选原始PCAP。

## 5. 网络定义

保留RF二维前端→原reshape→一维卷积分类器的总体结构，输出五类logits。多核均作用于原始时间槽轴，放在reshape之前；reshape之后的轴不能直接称为原1800时间轴。

共同锚点width=2。多核分支使用(方向核高,时间核长)=(3,3)/(3,5)/(3,7)，stride=1；方向补零1，时间分别补零1/2/3，分支输出方向高度2、时间长度1800。方向核高3不代表存在第三种真实方向。

每个分支为Conv2d→BN→ReLU，输出通道按3/5/7核分配22/21/21，拼接共64通道，然后1×1 Conv2d→BN→ReLU融合。

| 变体 | 接法与接口 |
|---|---|
| 单核 | 原CNN结构，首层按输入2或10通道适配；width=2。 |
| 替换型 | 多核整体替换原首个Conv2d/BN/ReLU单元，1×1投影64→64，接原后续二维前端；不重复执行旧首个BN/ReLU，也不裁剪回原首层长度。 |
| 前置型 | 多核前置，1×1投影64→输入通道数2或10，随后进入完整CNN；共同锚点下原首层输出64通道。直接CNN(F(x))，无输入残差。 |

替换型的same填充改变首单元输出长度，后续形状应以实际张量验证，不能强套原1797槽中间形状。各变体保持可用的后续池化、reshape与五类输出。

各分支共享固定中间通道预算，不声称各模型严格等参数。记录实际参数量。全部从头初始化，不迁移旧最优权重；新增Conv2d等沿用RF初始化规则，保留其Conv1d既有默认初始化行为。

## 6. 训练、选模与停止

| 参数 | 已确认取值 |
|---|---|
| 优化器 | Adam |
| 初始学习率 | 0.001 |
| 学习率公式 | max(0.000001, 0.001×0.5^(epoch/30))，epoch从0计 |
| weight_decay | 0.001 |
| batch_size | 200，小样本自然形成不足200的批次 |
| width | 2 |
| dropout_2d / dropout_1d | 0.05 / 0.1 |
| 损失 | 普通、不加权交叉熵 |
| 选模 | 最佳验证Macro-F1；同分选择较早epoch |

raw/log1p共享锚点，不新增调参。checkpoint选模使用实际最佳Macro-F1；用于停止判断的0.001显著提升阈值不改变checkpoint选取。

v2正式训练接口默认至少60轮、最多200轮，沿用既有严格规则：Macro-F1相对显著最佳值连续20轮没有至少0.001提升，且最近两段各10轮平均验证交叉熵的相对改善不足1%，两者同时满足才判定收敛。相对改善为(前段均值−后段均值)/前段均值，前段为0时沿用原实现按0处理。达到200轮仍不满足时停止并报告达到上限、未收敛。

复用已有验证停止语义，但新学习率必须读取本节锚点，不能调用硬编码旧0.0005/0.2公式。本轮实际每组只运行2轮smoke，属于预算结束，不宣称收敛。

执行使用FP32、固定seed、关闭TF32/AMP及cudnn benchmark，DataLoader workers=0、数值线程4。非有限损失或OOM停止报告，不自动降模型规模或改变样本预算。

## 7. 公共接口、身份与兼容

扩展现有python -m agentprint公共CLI，新增显式fit-bins，随后prepare读取已完成的拟合产物，再train、evaluate。prepare不隐式拟合。新功能使用schema_version=2，明确表达特征、拟合产物、模型变体及训练规则；公共入口保留旧v1行为。

模块职责边界为：拟合负责train分布与边界；补充缓存负责IAT计数与身份；数据加载负责按sample_id关联和输入变换；模型构造负责三种前端；训练/评估负责checkpoint、指标和恢复。复用既有解析、指标与恢复能力，不顺带开展无关重构。

旧schema_version=1仍严格按原规则解析，不自动注入新字段，不改变原配置、预处理指纹或旧checkpoint恢复身份。扩展特征/模型使用独立版本，旧缓存、原配置、真正旧checkpoint的读取、评估及恢复需通过回归。关闭新增模块的原模型初始化与输出必须一致；该回归使用原协议参数，而非要求width=2新锚点等同旧默认模型。

实验身份覆盖特征定义、模型结构、拟合指纹、manifest、基础及补充缓存、输入变换、训练参数和种子。选模候选范围必须包含新特征/模型身份，避免仅按raw/log1p合并不相容候选。评估和恢复根据checkpoint保存的定义重建模型，核验当前数据与配置，不能盲信CLI开关。

## 8. 中断恢复与存放位置

- fit-bins按episode提交进度，保存每episode最多4096个抽样值和来源身份；恢复时只复用身份匹配的已完成记录，不保存完整逐包序列。
- prepare按完整256样本IAT分片提交进度；中断后复用已提交且身份匹配的分片，未完成部分重新处理。
- train按完整epoch恢复模型、Adam状态、随机数、shuffle、最佳模型及停止历史；沿用日志超前归档及身份核验机制。

本地编辑并使用Git管理。服务器所有新增缓存、拟合暂存、日志、checkpoint、验收数据和报告均放在/root/autodl-tmp/ant-workspace数据盘内，原始数据不改写。进入远程验收前，先提交对应实现，使报告能记录准确Git版本。

## 9. 自动化测试与真实小样本验收

主要测试边界为公共fit-bins→prepare→train→evaluate及产物、身份、恢复结果；必要的公开模型接口测试覆盖形状、交叉熵与反向传播。

| 验收范围 | 核验内容 |
|---|---|
| 手算IAT与桶 | 跨方向/连接前驱、首包、零间隔、稳定排序、当前包槽号与方向、精确边界归右、重复边界与末桶。 |
| 拟合 | train-only、episode等权、最多4096确定性抽样、遍历顺序独立、无大于零间隔的处理、smoke与全量身份区分。 |
| 缓存和身份 | uint64形状及计数、按sample_id跨分片关联、错误缓存/拟合/来源拒绝、拟合及分片中断恢复。 |
| 模型 | 支持矩阵的公开接口形状、有限损失及梯度；两种多核接法；原初始化/输出一致性。关闭IAT的测试不构成额外训练实验。 |
| 训练与评估 | 最优checkpoint选择、不同变体候选隔离、从checkpoint重建、学习率与严格停止边界、完整epoch恢复。 |
| 旧协议 | 真正旧v1配置、缓存、checkpoint的读取、评估、恢复；不能仅用新代码重建所谓旧夹具。 |
| test路径 | 用合成夹具验证显式test评估；本轮不读真实test数据。 |

真实小样本来自现有有效清单，按PCAP大小优先、sample_id打破并列，每类最多4个train、2个val，总计最多20/10。不额外要求messages标注存在，不把旧双任务smoke的标注筛选条件引入本次场景分类。

仅以所选train拟合桶边界，准备所选train/val的IAT补充缓存，并关联已有基础MTAM。6种IAT开启配置串行运行，每组seed=42、2轮，再验证最佳checkpoint评估及恢复路径。CPU执行单元/集成测试；真实6组优先使用可用GPU，无GPU时用CPU，不自动缩小模型和样本预算。

验收报告包含Git版本、所选样本清单、拟合与缓存身份、实际参数量、执行硬件、各组命令/轮数/结果、恢复核验及失败项。小样本指标只判断流程可执行，不用于选最佳方法、比较论文效果或宣称收敛。
