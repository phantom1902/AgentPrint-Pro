# AgentPrint 适配 ANT：设计磋商

状态：磋商中。本文记录已确认范围和待决问题，尚不是可执行的开发规格。

磋商方式：按用户要求，一次只提一个问题。

## 已确认

- 开发五类整 episode 场景分类、47 类给定片段分类两个独立任务。
- 方法依据为用户指定的 AgentPrint 论文，研究数据为现有 ANT。
- 片段来自已有标注；两个任务分别训练和评估。
- 给定片段采用当前标注起点到下一标注起点的区间，最后一段到 PCAP 结束；异常标注的处理另行决定。
- 重复起点只排除该组对应的不确定区间，保留同一 episode 的其他有效片段，不整条排除。
- 无可用包或时长为零的片段不进入片段分类训练和评估，单独报告排除数量、类别分布和覆盖率；暂不增加最少包数或最短时长门槛。
- 首版排除无法可靠对齐的标注区间并记录原因，保留其余有效片段；全面修复时间对应关系不作为首版完成条件。
- 两个任务的 MTAM 字节量统一使用 IP 包总长度，包含 IP 头、运输层头和数据，不包含链路层头。
- 保留纯 ACK、无数据的 SYN/FIN 等控制包，计入 MTAM 的包数和字节量。
- 两个任务各自按样本完整时长等分 1800 个槽，输入均为 2×2×1800；不采用固定秒级槽宽后截断的方案。
- 实现原始统计与逐元素 log1p 两种输入配置，各任务独立用验证集比较和选择，测试集不参与选择。
- 术语见根目录 CONTEXT.md；任务边界见 ADR 0001。

## 第二轮：片段质量规则

### Q5 已确认 B：只排除不确定区间

用户选择保留 episode 的其他有效片段。起点重复组的区间为该时间到下一个不同起点，末组到 PCAP 结束；该组全部标注及对应时间范围不构造监督片段，不任意保留其中一条，也不把前后片段跨该范围拼接。原始数据保持完整，排除仅体现在片段样本清单中。此质量规则仅针对 47 类片段任务；episode 场景任务的样本由其自身质量规则决定。

例：10 秒同时标注 N011 和 N014，20 秒标注 N003，则 [10,20) 的单标签归属不确定。已有核验显示，训练集 414 个 codex episode 存在重复起点，排除整条 episode 会连同其中其他可用区间一并丢弃；最终有效片段数须在规则确定后统计。

### Q6 已确认 A：排除无包或零时长片段

在已确认区间规则下，若片段没有可用包或时长为零，则不作为片段训练和评估样本，不以全零 MTAM 替代。报告排除数量、类别分布和覆盖率，保留原始数据与排除原因。

仅包数少、时长短但仍有效的片段不因此排除；暂不额外引入最少包数或最短时长阈值。该规则仅针对片段分类，不能据此自动排除其所属 episode 的场景分类样本。

### Q7 已确认 A：首版允许排除无法可靠对齐的部分

已有探索检查发现部分标注时间不在捕获范围内，另有 Qwen 日志时间以 1970 年形式表示。具体时间基准需核查，不能仅凭年份判断样本失效，也不能猜测偏移量。

首版只纳入能够可靠对齐的片段；无法对齐的部分排除并记录原因和覆盖率，保留同一 episode 其余可用片段。若整个 episode 的日志时间基准都无法确认，则该 episode 暂不能提供监督片段，但不因此失去有目录标签的场景分类资格。时间修复必须有可验证依据，不猜测偏移量；全面修复这些样本不作为首版完成条件。

## 第三轮：MTAM 输入约定

### Q8 已确认 A：字节量使用 IP 包总长度

两个任务的 MTAM 均需为每个包确定一个字节数。备选为 IP 包总长度、链路帧长度、运输层载荷长度。AgentPrint 正文的 packet size 与图注未完全消除此层级歧义，此项属于明确记录的适配选择。

用户确认使用 IP 包总长度，包含 IP 头、运输层头和数据，不包含链路层头；这样可减少不同抓包链路头格式对字节统计的影响。IPv4 对应总长度字段，普通 IPv6 对应固定头长度加其 payload length。该选择不能用链路帧长、捕获字节数或 TCP 载荷长度静默替代。抓包截断等数据质量问题需识别并记录，不能把截断长度冒充原始 IP 包长。

### Q9 已确认 A：保留无运输层载荷的控制包

同一 IP 包长口径下，纯 ACK、无数据的 SYN/FIN 等 TCP 包仍有非零 IP 长度。用户确认保留这些包并计入包数和字节量，两个分类任务使用相同规则。

这一选择保留连接建立、确认与关闭等通信节奏，效果需实验验证。无运输层载荷不等于区间无包，不能以 Q6 为由自动剔除此类包。是否处理重传及非 TCP 协议另行确定。

### Q10 已确认 A：按各样本完整时长等分 1800 槽

论文方法正文将每条 trace 的持续时间均分成 1800 个时间槽。用户确认分别按完整 episode 的捕获时间范围和给定片段的标注区间等分，不因样本较长而截断，不采用固定秒级槽宽后截断或补零的替代方案。

两个任务的输入均为 2×2×1800。例如 180 秒的 episode 每槽 0.1 秒，18 秒的片段每槽 0.01 秒。该选择保留各样本范围内的时间比例，但不同样本每槽对应的绝对秒数不同。片段时间范围取已确认的标注区间，不因首尾无包而自行收缩成首包至末包。

### Q11 已确认 A：验证集比较原始统计与 log1p 输入

包数和字节量的数值范围不同。当前检查的 RF 原始 TAM 提取和训练源码直接使用包数统计，没有显式输入对数变换；该参考模型只有包数通道，不能由此证明 AgentPrint 两统计通道的具体缩放方式。AgentPrint 原文也没有给出明确的输入归一化公式。

用户确认同时实现原始统计与逐元素 log1p 两种配置，分别通过各任务验证集比较后选择。两个任务不要求选出相同的输入变换；各自采用哪种配置由各自的验证结果决定。

log1p(x)=ln(1+x) 保持空槽为零，并压缩大数值；它是否改善 ANT 分类需实验比较，不作为论文已给定设置。比较时固定其余训练条件，最终测试集不参与选配置。

## 第四轮：分类损失与模型选择

### Q12 待决：普通交叉熵还是类别加权交叉熵

两个任务均为独立的单标签多分类。RF 原训练源码明确使用无类别权重的 CrossEntropyLoss；AgentPrint 论文没有明确其具体损失配置。现有标签分布不均衡，但片段质量筛选后的有效样本数尚需重新统计。

备选为首版两个任务均以普通交叉熵建立基线，或使用类别加权交叉熵。建议普通交叉熵，尚未采纳。若选择加权，权重公式须另定，并仅根据相应任务的有效训练样本计算；不能直接以未筛选的消息行数作为片段训练分布。两个任务分别计算分类损失，不引入联合损失。
