# 用训练集episode等权分布确定共享IAT桶

本任务以完整episode为分类单位。为减少高包数episode对桶边界的支配，采用各episode内部大于零间隔分布等权混合，替代全局每个间隔等权；入站和出站共享边界、分别计数。每个训练episode最多确定性均匀无放回抽取4096个大于零间隔，按该episode抽样数归一化权重；这近似完整的episode等权分布，不是平均各episode的分位点。

固定8桶，其中零间隔独占1桶，其余7桶通过训练分布的1/7至6/7六个经验分位点划分。分位点使用实际整数纳秒值，重复边界保留并报告空桶。所有模型、输入变换与训练种子共享同一拟合产物；拟合清单、抽样规则和边界进入产物身份。小样本拟合单独标记，不能复用为全量拟合。该选择来自Q7/Q9/Q11–Q13/Q17/Q23/Q24/Q36，效果仍需后续正式实验验证。
